# Suspension Dynamics Lab — 懸吊彈簧阻尼模型分析

把 `new/Model_testing` 的參數設定、模型分析與結果檢視整合在同一個離線桌面工具中。四種模型分類各有自己的輸入與結果紀錄，無須先執行 `data_creator.py`，也無須產生 GIF。原始研究資料夾維持原狀。

介面沿用 SuspensionGeometryLab 的參數設定方式，曲線使用從 VehicleLab 收進本套件的 **Tkinter Canvas 圖表**。動畫直接更新 Canvas 元件，不使用 Matplotlib、不播放預先錄製的 GIF，也不在播放時重新積分。

## GitHub Pages 網頁版

開啟 [Suspension Dynamics Lab](https://dannyhsuc10.github.io/Suspension-model/) 即可在瀏覽器操作。首次開啟會下載 Pyodide 與 NumPy。模型、參數換算、RK4 求解及結果統計與桌面版共用同一套 Python 程式，分析與匯入檔案都在瀏覽器處理。網頁支援四類模型、播放、疊圖、匯入專案 JSON，以及匯出 NPZ、CSV、SVG、PNG、HTML。

本機預覽可在儲存庫根目錄執行以下命令，再開啟 `http://127.0.0.1:8000/`。

```powershell
python web/build.py outputs/pages
python -m http.server 8000 --bind 127.0.0.1 --directory outputs/pages
```

GitHub Pages 的發布來源選擇 **GitHub Actions**。`main` 上的網頁或求解器更新會觸發 `Publish suspension workbench`，由 `web/build.py` 打包靜態網頁與共用 Python 模組。

## 啟動

雙擊 **Start-SuspensionDynamicsLab.bat**，或在本資料夾執行：

```powershell
python run.py
# 或
python -m suspension_dynamics
```

需要 **Python 3.10+、Tkinter、NumPy 1.24+**；PNG 匯出另需 Pillow。這台電腦的 Codex Python 已有這些套件，啟動檔會自動選用。其他環境可先執行：

```powershell
python -m pip install -r requirements.txt
python -m pip install Pillow  # 僅 PNG 匯出需要
```

整個 `SuspensionDynamicsLab` 可獨立複製使用，不依賴 `SuspensionGeometryLab`、`VehicleLab` 或 `new`。

## 操作流程

1. 選擇上方四類頁籤與模型版本。
2. 按「車輛／彈簧阻尼設定」修改全車或各模型的專用參數，再按「套用全部設定」。1/4 與半車的灰底欄位會顯示由全車換算的數值。輸入錯誤時會保留草稿並顯示原因，不會部分套用。
3. 在左側「模型與輸入」選擇凸塊、階躍、正弦、隨機路面、ISO 路面或加速度情境，設定時間、步長和作用輪位，按 **F5／計算此模型**。不適用的欄位會停用。前後／全車可開關後軸輪跡延遲；全車另有凸塊與縱橫向加速度同時輸入。
4. 結果區左側顯示模型動畫或全車儀表板，右側顯示訊號圖。拖曳中間的分隔線可調整兩側寬度。下方的播放按鈕、逐步、倍速與時間滑桿會同步更新兩側畫面。模型動畫預設位移 1 倍，也可獨立放大至 20 倍。幾何圖的水平與垂直軸維持 1:1 等比例，側視輪胎為正圓，前視為矩形。輪胎與車身高度屬模型示意尺寸。
5. 「曲線選擇／比較」可選位移、懸吊行程、速度、加速度、車身姿態、輪荷、懸吊力、模態通道力、能量等。Ctrl／Shift 可選多條曲線。曲線可縮放、平移，雙擊重設。1/4 與 1/2 前後模型固定顯示側視，1/2 左右模型固定顯示前視。全車儀表板的四輪法向輪荷與模態／直推力柱狀圖，以及目前姿態數值，會跟隨播放時間更新。
6. 「計算本類全部模型」會計算相容版本。勾選疊圖比較，只納入**相同參數與相同輸入**的模型，每個版本取最近一次結果。
7. 「顯示結果」保留本類最近 20 次分析，包含不同設計的快照。新設定不會改寫舊結果。1/4 與半車的「套用分析輸入」會載回分析條件與本類專用設定，重算時使用目前的全車參數。

1/4 模型動畫的橘色路面輪廓取自 `Road Q`。輪胎正下方對應目前取樣，前方與後方分別顯示後續與先前的路面高度。ISO 路面以設定車速將時間換成水平距離，其餘輸入以 1 m/s 的示意速度繪製。超出紀錄的部分沿用端點高度。

1/4、1/2 左右、1/2 前後和全車模型都可在「分析輸入」選擇 **ISO 8608 Class A、B 或 C**，設定「車速」和「隨機種子」後按 **F5**。車速的單位是 m/s，例如 20 m/s 等於 72 km/h。從「輸入開始」起，模型以 `x = 車速 × 經過時間` 取樣。同一等級和種子會重現同一條路面，車速加倍時會在一半的時間內通過同一段起伏。若車速提高後輸出取樣太疏，請縮短「輸出時間步長」。

「路面作用輪位」決定哪些輪位會收到 ISO 路面輸入。選中的輪位共用同一條合成輪廓。1/2 前後與全車模型可勾選「同一輪跡延遲至後軸」，讓後輪在「軸距 ÷ 車速」之後進入同一段路面。

合成路面採用 ISO 8608:2016 附錄 B、C 的分級曲線。A、B、C 級在參考空間頻率 0.1 cycles/m 的名目位移 PSD 分別為 16、64、256 × 10⁻⁶ m³，譜斜率為 −2。合成頻帶為 0.011–2.83 cycles/m，路面高度以起點為零，空間輪廓每 4,096 m 重複。 [ISO 8608:2016](https://www.iso.org/standard/71202.html)

1/4 模型在「模型與輸入 → 參數來源（全車）」選擇 FL、FR、RL 或 RR，預設 FL。每輪簧上質量依全車簧上質量及重心到前、後軸的距離分配，同軸左右各取一半。簧下質量取對應車軸的每輪值，輪胎剛性與阻尼取該軸的每輪元件值乘以 MR²。輪胎阻尼用於「2 DOF · 雙彈簧阻尼」版本。

1/2 左右模型可選「側向加速度」或「凸塊＋側向加速度」。`ay` 單位為 m/s²，正值產生左側上升的側傾，負值反向。`ay` 從「輸入開始」起，在設定的「加速度上升時間」內平滑升至指定值，並維持到模擬結束。雙質點版本以作用在左右簧上質點的等效力偶呈現側傾。

1/2 前後模型在「模型與輸入 → 參數來源（全車）」選擇「前軸參數」或「後軸參數」。選定車軸的 heave、直推、輪胎與每輪簧下質量會用於前後兩端，軸距、重心位置與前後 Anti 沿用全車設定。預設使用前軸，切換後按 **F5** 重算。1/2 左右模型的兩輪共用全車前軸的每輪簧下質量、輪胎與直推設定。

「數值結果」與 HTML 報告包含每個訊號的穩態平衡點、2% 安定時間與超越量。平衡點由最後的固定輸入解出，單位與訊號相同。安定時間從「輸入開始」計時，取輸入完成後進入 2% 安定帶且直到模擬結束都沒有再超出的第一筆取樣。若終點仍超出安定帶，或輸入尚未完成，顯示「未安定」。

2% 安定帶及超越量以輸入前到穩態的變化量為基準，下降訊號沿下降方向判斷超越。回到原平衡點時，安定帶改以模擬中的最大偏差為基準，百分比超越量顯示 `—`。持續正弦、隨機路面、ISO 路面、舊資料或無法求出唯一平衡點的情境，三項指標顯示 `—`。

計算在背景執行，可按「停止計算」，已完成的模型結果會保留。切換分類會暫停播放，各類資料仍在。按「匯入」或 **Ctrl+O** 可載入專案，按 **Ctrl+S** 可儲存。專案名稱前的 `*` 表示設定尚未儲存。

匯入支援 Dynamics 專案與 Initial Sizing 的新版三類 JSON，也支援舊版 `parameters.full` 匯出。若專案名稱或車輛參數有缺少的鍵、`null` 或空白字串，會列出缺失欄位、單位、JSON 路徑和預設值。可逐欄自行輸入，留空則使用內建預設值。按「補齊並匯入」後會驗證整份專案，確認成功後可另存修補結果。按「取消」會回到目前專案。

## 四類、十三種模型

| 分類 | 版本 | 自由度與用途 |
| --- | --- | --- |
| 1/4 | single / one_eighth | 1 DOF，串聯 ride rate；無阻尼／含阻尼 |
| 1/4 | double / quarter | 2 DOF，簧上與簧下；無阻尼／含阻尼 |
| 1/2 左右 | 2mass_2dof / 2mass | 左右雙質點，2／4 DOF，沒有獨立車身慣量 |
| 1/2 左右 | half_2dof / half | 升沉與側傾，2／4 DOF；4 DOF 含輪胎與 RC 傳力 |
| 1/2 左右 | rollcenter_all | 5 DOF，另外加入車架傳力虛擬質量；原程式雖標 4 DOF，實際有額外狀態 |
| 1/2 前後 | half_2dof / half | 一側半車的升沉與俯仰，2／4 DOF；4 DOF 含輪胎與 Anti |
| 全車 | rigid | 7 DOF：升沉、側傾、俯仰與四個輪胎自由度 |
| 全車 | flex | 8 DOF：前後側傾分開，以車架扭轉彈簧阻尼耦合 |

### 可編輯參數

- **1/4**：可編輯懸吊彈簧 `ks`、阻尼 `cs`、MR 與阻尼比。`ms`、`mu`、`kt`、`ct` 由全車換算。
- **左右**：簧上質量與側傾慣量按前軸份額 `lr / (lf + lr)` 分配。輪距、RC、heave、roll、直推與輪胎取自全車前軸。虛擬車架傳力的 k、c、m 在左右頁籤設定。
- **前後**：簧上質量與俯仰慣量取全車的一半。所選車軸的單側 heave 以 `2 × 全車通道 k、c` 換算，保留原 MR。輪胎和直推取該軸的每輪值。軸距、CG 與前後軸 Anti 比例取自全車。
- **全車**：在「車輛／彈簧阻尼設定」的全車頁籤設定各通道的 k、c、MR。直推用 `corner_f`、`corner_r`，輪胎用 `tire_f`、`tire_r`。每組數值以單輪為單位，由同軸左右輪共用。其餘模態通道為 `heave_f`、`heave_r`、`roll_f`、`roll_r`、`roll_c` 和 `warp`。

數值預設取自原始 `Parameter_set/Suspension.py`。1/4 模型可勾選「依阻尼比 ζ 自動估算阻尼係數」。對應的懸吊阻尼欄位會變成灰底唯讀，並隨阻尼比、剛性、質量等輸入更新。取消勾選即可手動編輯。按「套用全部設定」後，勾選狀態與阻尼係數一併納入專案。左右與前後模型直接使用從全車換算的阻尼。

舊專案的四輪簧下質量、直推和輪胎參數會在載入時按車軸取左右平均。直推和輪胎的 k、c、MR 各自取平均。原有結果快照保留計算當時的四輪值。

**MR 定義：本工具為彈簧行程／輪端行程，輪端 k、c = 元件值 × MR²。VehicleLab 使用倒數定義，請勿直接把它的 MR 數字照抄。** 全車車架扭轉 k 的單位是 N·m/rad，其他線性通道 k 是 N/m。

## 結果保存與舊資料

「匯出結果」提供：

- **NPZ**：完整原始時間序列、參數快照、單位、警告與求解資訊；可再次開啟，不需重新計算。
- **CSV**：全部訊號，欄名包含單位，UTF-8 BOM，可直接用 Excel 開啟。
- **SVG／PNG**：目前選取的曲線與顯示視角。PNG 需 Pillow。
- **HTML 報告**：曲線、最小／最大／時間加權 RMS／絕對峰值、完整輸入與計算資訊；可由瀏覽器列印為 PDF。

修改參數後，按 **F5／計算此模型** 產生新的結果。需要查看已保存的 NPZ 或舊版 `result.pkl` 時，可從命令列以 `--result` 指定檔案。舊資料以原始符號與數值顯示，並提供 `raw:*` 欄位。舊資料的動畫採預設示意尺寸，舊參數可在「模型說明／計算快照」查看。

PKL 匯入器只允許原 logger 使用的 NumPy 數值陣列類型，拒絕其他可執行物件。新 NPZ 格式不使用 pickle。

專案 JSON 將車輛參數、阻尼比、車架傳力和 Tender 設定集中存入 `parameters.full`。開啟時套用內建的預設分析設定。舊 JSON 的前 Anti-dive 和後煞車 Anti-lift 會分別帶入新的前、後軸 Anti 比例。需要保留當次分析輸入與計算結果時，請匯出 NPZ。

可開啟 [Vehicle_initial_settings.json](projects/Vehicle_initial_settings.json) 或其他由 Initial Sizing 匯出的全車 JSON，依匯入對話框補齊缺少的參數。載入單一參數區塊時，四分之一車的 `ks` 為「前 Heave 主簧與 Tender 串聯剛性，加上前 Roll 剛性，再除以 4」。Initial Sizing v3 的 `heave_f_k` 和 `heave_r_k` 直接載入。四分之一車使用 v3 的 `heave_f_k` 作為前主簧簧率，舊版則以 `4 × heave_f_k` 還原主簧簧率。Tender 停用或沒有有效剛性時，使用純主簧。`mr` 取 `corner_f_mr`，`cs` 使用阻尼比、前軸每輪簧上質量和 `ks` 估算。舊版分組 JSON 仍可開啟。

## 計算整理與適用範圍

新核心以靜態平衡點附近的線性 `Mq̈ + Cq̇ + Kq = f(t)` 統一處理。被動彈簧與阻尼用虛功轉換建立，確保力與力矩使用同一套座標及力臂。RK4 依系統特徵值、輸入頻率與凸塊長度自動細分；輸出步長不限制內部積分精度。

原程式尚未完全整理，這次不直接把原檢視器包進視窗。以下已修正並在 [MODEL_NOTES.md](MODEL_NOTES.md) 說明：前後模型輪胎阻尼方向、heave 額外除以二、右輪路面速度、各簡化版本的模態倍率，以及全車的側傾半輪距、簧上質量與落後一步的狀態。新計算結果因此不保證等於舊 PKL。

位移向上為正；側傾正值為左側上升，俯仰正值為車頭上升。ax 正值為加速、負值為煞車。路面階躍不包含理想速度脈衝；隨機路面為固定種子的線性插值。前後族以一側半車的 `2ms + 2mu` 為總質量，與全車族的總質量欄位不同。

這是小角度、線性垂直／側傾／俯仰分析，RC／Anti 使用常數幾何傳力；沒有非線性雙 A 臂、限位塊、完整輪胎摩擦、失去接地後的碰撞／再接觸或實車校準。輪荷含靜態重量，負輪荷會提示模型已超出接地假設；不會把負值偷偷截成零。

## 測試與程式化使用

雙擊 `Start-Tests.bat`，或執行：

```powershell
python -m unittest discover -s tests -v
python -m suspension_dynamics.cli --family full --model flex --scenario combined --duration 3 --output outputs/full_case
python -m suspension_dynamics --project projects/LP03.json
python -m suspension_dynamics --result outputs/full_case.npz
```

命令列使用與介面相同的計算核心，輸出 NPZ、CSV 與 HTML。測試包含全部模型／相容情境、解析解、左右鏡射、能量與虛功、輪荷／力矩守恆、時間收斂、舊資料轉存、原生介面、背景取消與隔離複製啟動。
