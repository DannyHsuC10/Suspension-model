# 懸吊接點命名說明

本文件以 Vehicle Lab 主程式的雙 A 臂懸吊為主。每個車輪有 **8 個接點（硬點，hardpoints）**，四輪共 **32 個接點**；前、後輪使用相同名稱。

## 四輪位置代號

左右皆以駕駛坐在車內、面向車頭的方向判斷。

| 代號 | 英文 | 中文 |
| --- | --- | --- |
| `FL` | Front Left | 左前輪 |
| `FR` | Front Right | 右前輪 |
| `RL` | Rear Left | 左後輪 |
| `RR` | Rear Right | 右後輪 |

例如 `FL / UBJ` 代表「左前輪的上球接頭」。在 JSON 中可找到 `geometry.corners.FL.UBJ`。

## 每輪的 8 個接點

| 名稱 | 英文名稱／縮寫拆解 | 中文定義與位置 |
| --- | --- | --- |
| `UFI` | Upper Front Inner | 上 A 臂前側內接點：上 A 臂與車架連接的前側樞軸中心。 |
| `URI` | Upper Rear Inner | 上 A 臂後側內接點：上 A 臂與車架連接的後側樞軸中心。 |
| `UBJ` | Upper Ball Joint | 上球接頭：上 A 臂與輪座（羊角）連接的球頭中心。 |
| `LFI` | Lower Front Inner | 下 A 臂前側內接點：下 A 臂與車架連接的前側樞軸中心。 |
| `LRI` | Lower Rear Inner | 下 A 臂後側內接點：下 A 臂與車架連接的後側樞軸中心。 |
| `LBJ` | Lower Ball Joint | 下球接頭：下 A 臂與輪座（羊角）連接的球頭中心。 |
| `ROD_IN` | Tie Rod Inner | 轉向／束角拉桿內接點：前輪接齒條端；後輪接束角桿的車身端，若設定後輪轉向則隨後齒條橫移。 |
| `ROD_OUT` | Tie Rod Outer | 轉向／束角拉桿外接點：拉桿與輪座上轉向臂連接的接頭中心。 |

縮寫中 `U/L` 表示上／下，`F/R` 表示該 A 臂接點的前／後，`I` 表示車身內側，`BJ` 表示球接頭。這裡的前／後與輪位代號不同，例如 `RL / UFI` 是「左後輪上 A 臂的前側內接點」。

連接關係如下：

- 上 A 臂：`UFI`、`URI`、`UBJ` 三點。
- 下 A 臂：`LFI`、`LRI`、`LBJ` 三點。
- 轉向／束角拉桿：`ROD_IN` 至 `ROD_OUT`。
- 轉向軸（主銷軸線）：通過 `LBJ` 與 `UBJ` 的直線。

`UFI`、`URI`、`LFI`、`LRI` 固定於車架；`UBJ`、`LBJ`、`ROD_OUT` 隨輪座移動；`ROD_IN` 只隨對應齒條橫移。座標填寫樞軸或球頭的中心位置。

## 座標與單位

- `x`：向車頭為正；前軸 `x = 0`，後軸 `x = -軸距`。
- `y`：向車輛左側為正；車身中心線 `y = 0`，左側為正、右側為負。
- `z`：向上為正；靜態地面為 `z = 0`。
- 硬點編輯器與 CSV 使用 **mm**；專案 JSON 與計算核心使用 **m**，例如 `280 mm = 0.280 m`。
- 左右鏡射為 `(x, y, z) → (x, -y, z)`。

CSV 範例（`group` 固定填 `corners`）：

```csv
group,corner,point,x_mm,y_mm,z_mm
corners,FL,UFI,140,280,348.2
```

## 其他幾何點與模型範圍

輪心 `center`、輪胎接地點 `contact`、瞬時中心 `IC` 與滾動中心 `RC` 由程式計算，未列入每輪 8 個輸入硬點。

目前主程式沒有推桿／拉桿式避震機構的接點、搖臂、彈簧／避震器固定點或防傾桿接點。彈簧、避震器與防傾桿透過剛性、阻尼及運動比參數描述；`ROD_IN / ROD_OUT` 專指轉向／束角拉桿。

## `new/suspension_geo` 的命名對照

此資料夾的二維分析使用另一套命名，常見對照如下：

| 名稱 | 定義／主程式對照 |
| --- | --- |
| `kua` | 上控制臂與羊角接點，對應 `UBJ`。 |
| `lak` | 下控制臂與羊角接點，對應 `LBJ`。 |
| `UBJ` / `LBJ`（`static` 3D） | 上／下 A 臂在主銷上的外端球接頭；在相同高度合併 SV 的縱向座標與 FV 的橫向座標，四個輪位各自建立。 |
| `ground` / `axis_top`（`static` 3D） | 合成主銷軸線的地面交點／頂端；與同輪位的 `UBJ`、`LBJ` 共線。 |
| `cpb_ru` / `cpb_rl` | 前視模型的上／下控制臂車身側等效點；各自代表二維幾何，不能直接對應某一個前／後內接點。 |
| `tie_point`（圖中 `P_tie`） | 上視模型的轉向拉桿外點，對應 `ROD_OUT`。 |
| `rack_left` / `rack_right` | 左／右齒條端點，對應各前輪的 `ROD_IN`。 |
| `aa_point` | 簡化上視模型的轉向旋轉參考點。 |
| `kg` | 初始主銷軸線與地面的交點參考；隨羊角移動後不一定仍位於地面。 |
| `gnd` | 輪胎接地參考點。 |
| `IC` | `static` 前視模型唯一的固定設計瞬時中心，由輪距、`fvsa` 與 `h_RC` 決定，不再另解新的瞬心。 |
| `RC` | 滾動中心；幾何計算點。 |
| `cg` | 車輛重心；車身參考點。 |
| `wheel_center` | `static` FV 的靜態輪胎中心；輪胎改以 3D 圓柱體顯示，不再使用四個外框角點。 |

前視模型使用二維 `X` 向圖右、`Y` 向上，與主程式的三維座標不同，匯入前需轉換。詳見該資料夾的 [README](new/suspension_geo/README.md)。

主程式詳細資料見 [懸吊幾何與運動學](計算說明/05_懸吊幾何與運動學.md)；實際接點清單見 [geometry.py](vehicle_lab/geometry.py)，座標範例見 [hardpoints.csv](examples/hardpoints.csv)。
